## DOI (Digital Object Identifier) Links

DOI links are permanent identifiers for academic papers. They can be accessed:

1. **Direct browser access**: Copy the DOI URL (e.g., `https://doi.org/10.1017/S0022112098003279`) into any web browser
2. **Via Google Scholar**: Search for the paper title
3. **Via university library**: Most universities have subscriptions providing free access
4. **Via ResearchGate/Academia.edu**: Authors often upload preprints

### Example: Verifying Conway (1998)

**Citation**: Conway, J. T. (1998). Analytical Solutions for the Actuator Disk with Variable Radial Distribution of Load. *Journal of Fluid Mechanics*, 378, 185-211.

**DOI**: https://doi.org/10.1017/S0022112098003279

**How to access**:
1. Open browser and visit the DOI link above
2. Or search Google Scholar for: "Conway Analytical Solutions Actuator Disk"
3. The paper is published in Journal of Fluid Mechanics (Cambridge University Press)

## Notes on Accessibility

1. **DOI persistence**: DOI links are permanent and maintained by publishers
2. **University access**: Most references available through university library subscriptions
3. **Open alternatives**: Many papers have preprint versions freely available
4. **Author copies**: Authors often share papers upon request via email or ResearchGate

## Alternative Access Methods

If direct URL access fails:

1. **Google Scholar**: Search paper title → Often provides PDF links
2. **ResearchGate**: Create free account → Request full text from authors
3. **Sci-Hub** (use responsibly): Last resort for papers behind paywalls
4. **University VPN**: Access via institutional subscriptions
5. **Interlibrary Loan**: Request through university library

## Contact for Verification

If you need help accessing any reference:

1. Check your university library's online catalog
2. Use the library's interlibrary loan service
3. Search Google Scholar for author-uploaded versions
4. Contact the paper's authors directly (email usually in paper)
